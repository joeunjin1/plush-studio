# PLUSH STUDIO
한국어 3D 인형 디자인 편집기. 정적 웹사이트이며 WebGL이 필요합니다.

- 곰, 토끼, 고양이 기본형 및 머리/몸통/귀/팔/다리/눈 간격 조절
- 바디/포인트/볼 색상, 3가지 표정, 가방고리
- 기기 내 자동 저장 및 JSON 프로젝트 저장/복원
- 정면/측면/뒷면/자유 시점, 자동 회전
- GLB 내보내기 (미터 단위, 입력한 완성 높이 반영)
- 현재 화면과 동일 배율의 삼면도 PNG

`dist`를 정적 웹서버로 제공하면 됩니다. Three.js 0.180.0을 로컬에 포함합니다.
프로젝트 저장은 브라우저 localStorage를 사용하며 계정 간 동기화하지 않습니다.
모델은 겹치는 부품으로 구성된 형태 검토용 모델입니다. 봉제용 2D 패턴, 시접, 재단 도면이나 단일 수밀 출력 메시를 생성하지 않습니다.

## v2: 삼면도 → 부위별 3D
- 가로 삼면도 1장 3등분 또는 정면/측면/뒷면 개별 업로드 (PNG/JPG/WebP)
- 이미지 정렬, 부위 이름/번호, 면별 클릭 윤곽 지정
- 정면의 폭과 측면의 깊이 프로파일을 타원 단면으로 연결하는 폐곡면 근사 생성
- 뒷면 윤곽은 검토 및 부위 구분용이며 형상 복원 입력으로 사용하지 않음
- 각 부위는 독립 메시: 이름, 위치, 회전, 크기, 색상, 표시, 복제, 삭제
- 표면 클릭으로 둥근 디테일/패치/뿔/고리/웨빙 배치
- 구분 색상, 보이는 부위 번호와 범례를 포함한 삼면도 PNG
- GLB에 부위 이름과 분리된 메시 보존, 전체 높이를 입력한 cm로 정규화
- JSON 프로젝트에 이미지/윤곽/부위/변형을 저장하고 복원, v1 프로젝트 호환

윤곽 기반 반자동 변환이며 AI 이미지 복원 서비스는 사용하지 않습니다. 윤곽의 숨은 경계는 사용자가 지정해야 하고 텍스처나 자수는 자동 복원되지 않습니다. 수평 단면이 분리되는 윤곽은 여러 부위로 나누어야 합니다. 독립 디테일은 결합 그룹으로 묶으면 다른 부위와 함께 이동합니다. 한 프로젝트에서 최대 80개 부위를 지원합니다. 브라우저 저장 용량을 초과하면 프로젝트 파일 다운로드를 안내합니다.

검증: 윤곽 메시의 유한 좌표/닫힌 토폴로지, 부위 편집과 저장 복원, 숨긴 부위 제외, GLB의 독립 메시 이름과 23cm 단위, 삼면도 내보내기 코드 경로를 확인했습니다. 브라우저 시각 QA는 수행하지 않았습니다.

## v3: 새 인형과 추가 부위 조립
- 새 인형 이름/시작 높이 지정. 현재 작업을 JSON으로 먼저 내려받고 새 편집을 시작하며, 같은 세션에서 직전 인형 복원 가능
- 본체 삼면도와 추가 부위 이미지를 별도로 저장. 각 추가 부위의 참고 이미지는 해당 부위와 함께 프로젝트에 보존
- 추가 부위는 정면 윤곽 한 장 + 지정 두께로 압출 생성하거나, 정면/측면 윤곽으로 입체 생성
- 부위 체크박스로 다중 선택, 결합 그룹 생성, 그룹 분리. 결합은 편집 가능한 조립 그룹이며 Boolean 메시 합집합이 아님
- 그룹 이동/회전/비례 확대 및 분리 시 월드 좌표 유지. 전단 변형을 피하기 위해 그룹 확대는 비율 유지
- 개별 부위의 가로/세로/깊이 cm 입력, 비율 유지 여부 선택, 인형 전체 높이 조정
- 선택한 부위 또는 그룹을 다른 부위 표면에 배치
- GLB에 조립 그룹 계층과 각 부위의 독립 메시를 함께 보존

v3 검증: 다중 선택 및 그룹의 이동/회전/확대, 분리 전후 좌표 유지, 그룹 저장 복원, GLB 계층, 본체와 부위 참고 이미지 분리 보존, 단일 윤곽 압출, 정확한 8cm 가로 치수, 새 인형 백업/직전 작업 복원을 코드 기반으로 확인했습니다. 실브라우저 시각 QA는 수행하지 않았습니다.
