# Plush Studio 실물 기준 B2B 커스터마이징 운영 전략

## 1. 서비스 정의

Plush Studio의 buyer 경험은 범용 3D 디자인 도구가 아니라 **실물 기준 상품을 선택하고, SKU마다 허용된 제작 사양만 구성한 뒤 공장 검토를 요청하는 B2B 커스텀 굿즈 주문 플랫폼**으로 운영합니다. 구매자는 확정되지 않은 색상·원단·인쇄 결과를 약속받지 않습니다. 대신 실사 5면 기준, 허용된 옵션, 안전 영역, 수량과 납기 정보를 한 흐름에서 검토 요청으로 제출합니다.

| 운영 단계 | 관리자 책임 | buyer 경험 | 확정 경계 |
|---|---|---|---|
| 상품 마스터 | SKU, 실측, 5면 원본을 private로 등록 | 공개 전에는 표시하지 않음 | 권리·사진·상품 동일성 검토 |
| 옵션 설계 | SKU별 컬러, 인쇄 방식, 안전 영역, 제약을 결정 | 활성화된 옵션만 선택 | 옵션은 공장 생산 보증이 아님 |
| 검토 요청 | 사진·메타데이터·개인화 방식 확인 | 수량·납기·로고/문구를 첨부 | Magic Link 후 요청 1회 접수 |
| 공장 검토 | 소재, 웨빙, 인쇄, MOQ, 샘플 가능 여부 검증 | 검토 결과를 요청 내역에서 확인 | 견적·발주·생산은 별도 확정 |

## 2. SKU별 옵션 원칙

각 상품은 같은 커스터마이징 화면을 공유하지 않습니다. 관리자는 상품별로 **허용 방식, 배치, 파일/텍스트 조건, 컬러, 표시 순서, 공장 검토 메모**를 정하고 buyer는 활성화된 값만 선택합니다. 현재 staging 구현의 첫 범위는 부직포 보냉백의 `body_color`와 `handle_color`이며, 로고·문구 방식은 기존 개인화 프로필로 분리해 결합합니다.

> 색상 선택 화면은 시각적 참고용입니다. 실제 원단·웨빙 색상, 재고, 염색 가능 여부, 인쇄 적합성, 최소 생산 수량은 공장 검토와 샘플 승인 후 확정됩니다.

## 3. 보냉백 실제 등록 전 체크리스트

1. 소유자가 제공한 10장 중 정면·좌·후·우·상면의 정확한 5장을 명시한다.
2. 최종 SKU, 한/영 상품명, 기본 색상, 완제품·카톤 치수, CBM, MOQ, 목표 리드타임을 확정한다.
3. 무인쇄 정면 사진은 원본 제공 사진을 우선한다. 생성된 시각화 이미지는 소유자의 명시적 승인이 없으면 buyer 공개에 사용하지 않는다.
4. staging `plush-studio-staging`에서 상품 마스터 → private 5면 등록 → 개인화 프로필 연결 → 본체/손잡이 색상 규칙 → 검토 후 public 복사를 순서대로 진행한다.
5. buyer는 비로그인 상태에서 상품·옵션·미리보기를 검토하고, 파일 보관·최종 요청만 Magic Link로 인증한다.

## 4. 현재 staging 경계

현재 구현과 UAT는 staging 코드, staging Supabase DB, staging Storage, staging Auth 안에서만 수행합니다. Production DB migration, public asset 복사, Auth redirect 허용 목록, 브랜드 권한, Production 배포는 별도 승인 및 별도 검증 없이는 수행하지 않습니다.
