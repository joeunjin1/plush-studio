# Plush Studio 판매상품 실사 기준 이미지 촬영·전달 가이드

## 목적

이 가이드는 대표가 판매할 실제 기본 상품을 **고객 선택용 공식 상품 라이브러리**와 향후 **3D 디지털 트윈 제작**의 기준 자산으로 전환하기 위한 촬영 기준입니다. 현재 Product Atelier의 절차형 미리보기는 형상 검토용 Concept/Prototype입니다. 실사 자료가 접수·검수되면 고객은 검수 완료된 실제 상품 기준 이미지를 먼저 선택하고, 해당 상품의 치수·소재·인쇄 옵션을 이어서 편집하게 됩니다.

> 사진은 판매·제작 기준을 확인하는 자료입니다. 사진만으로 봉제 패턴, 내부 충전량, 색상, 원단 광택, 부속품 치수를 자동 확정하지 않습니다.

## 1. 상품별 필수 촬영 세트

| 순서 | 촬영면 | 필수 여부 | 촬영 기준 | 파일명 예시 |
|---:|---|---|---|---|
| 01 | 정면 | 필수 | 제품의 중심선이 수직이 되도록 정면에서 촬영 | `basic-bear__front__v01.webp` |
| 02 | 좌측면 | 필수 | 카메라와 제품을 90°로 맞춰 깊이·옆선이 보이게 촬영 | `basic-bear__left__v01.webp` |
| 03 | 뒷면 | 필수 | 태그·지퍼·뒤 봉제선·후면 인쇄 위치가 보이게 촬영 | `basic-bear__back__v01.webp` |
| 04 | 윗면 | 필수 | 귀, 손잡이, 고리, 칼라, 입구 등 상부 구조가 보이게 촬영 | `basic-bear__top__v01.webp` |
| 05 | 우측면 | 권장 | 비대칭 구조, 로고, 포켓, 꼬리가 있는 경우 필수로 전환 | `basic-bear__right__v01.webp` |
| 06 | 바닥면 | 권장 | 바닥 원단, 받침, 라벨, 내구 구조가 있는 상품에 권장 | `basic-bear__bottom__v01.webp` |
| 07 | 디테일 | 권장 | 원단 결, 자수, 봉제선, 지퍼, 링, 인쇄, 라벨을 근접 촬영 | `basic-bear__detail-seam__v01.webp` |
| 08 | 치수 기준 | 필수 | 자·줄자와 제품을 한 프레임에 촬영하되 상품을 가리지 않게 배치 | `basic-bear__scale__v01.webp` |

## 2. 촬영 환경

| 항목 | 권장 기준 | 금지 또는 주의 사항 |
|---|---|---|
| 배경 | 무광의 흰색·연회색·연베이지 단색 배경 | 무늬 배경, 반사판, 강한 그림자, 복잡한 작업대는 사용하지 않습니다. |
| 조명 | 좌우 확산광 2개와 약한 상부 보조광 | 한쪽 직광만 사용하면 형태·색상이 왜곡됩니다. |
| 카메라 | 동일 기기, 동일 렌즈, 동일 노출·화이트밸런스 | 광각 렌즈와 인물 모드는 사용하지 않습니다. |
| 거리 | 전 촬영면에서 카메라와 제품의 거리를 고정 | 면마다 크기가 달라지면 정합 검수 시간이 증가합니다. |
| 프레임 | 제품 외곽에 8~12% 여백을 남기고 수평·수직을 맞춤 | 제품 일부가 잘리거나 비스듬하면 기준 이미지로 승인하지 않습니다. |
| 해상도 | 긴 변 2,000px 이상 원본 권장 | 메신저 자동 압축본만 전달하지 않습니다. |
| 색상 | 회색 카드 또는 기준 색칩을 첫 프레임에 촬영 | 서로 다른 조명·필터를 섞어 사용하지 않습니다. |

## 3. 인형·가방·티셔츠별 추가 촬영

| 제품군 | 추가로 보여야 할 구조 | 특히 필요한 근접 디테일 |
|---|---|---|
| 인형 | 귀·팔·다리·꼬리·키링 고리·앉는 자세 | 얼굴 자수, 눈·코, 원단 털 길이, 봉제선, 충전감 |
| 가방 | 손잡이·스트랩·입구·거싯·포켓·바닥 | 지퍼, 자석, 링, 버클, 안감, 상침, 로고 |
| 티셔츠 | 앞·뒤·소매·목둘레·밑단 | 리브 칼라, 봉제선, 원단 중량감, 인쇄/자수 위치 |

## 4. 전달 전 확인표

- [ ] 한 SKU·색상·사이즈마다 파일명을 같은 접두어로 통일했습니다.
- [ ] 정면·좌측면·뒷면·윗면·치수 기준 사진을 모두 포함했습니다.
- [ ] 배경·조명·거리·색상 설정을 촬영면마다 동일하게 유지했습니다.
- [ ] 원본 JPG, PNG 또는 고품질 WebP 파일을 압축하지 않고 전달했습니다.
- [ ] 판매·편집·3D 고도화에 필요한 사진 사용권을 보유하거나 적법한 사용 승인을 받았습니다.
- [ ] 실제 규격표, 소재명, 부속품 사양, 색상 코드가 있다면 같은 SKU 폴더에 함께 넣었습니다.

## 5. Plush Studio 접수 이후 절차

| 단계 | Plush Studio 처리 | 공개 상태 |
|---:|---|---|
| 01 | 파일 형식·해상도·필수 면·SKU 명칭을 자동 점검 | 비공개 접수 |
| 02 | 운영자가 실사 자료, 치수, 소재, 권리 정보를 검수 | 검수 중 |
| 03 | 정면·측면·뒷면·윗면을 공식 기준 세트로 고정하고 버전을 부여 | 내부 승인 |
| 04 | 공식 상품 카드와 고객 선택 화면에 검수된 대표 이미지·사양만 노출 | 고객 선택 가능 |
| 05 | 3D 메시, UV, PBR 소재, 부착 앵커, 공장 검토표와 대조 | 디지털 트윈 검토 |
| 06 | 실제 샘플·공장 검토를 통과한 경우에만 production-grade 상태로 승격 | 출시 승인 |

## 6. 첫 번째 권장 접수 대상

첫 세트는 **Basic Bear 1개 SKU, 1개 기준 색상, 1개 기준 크기**로 시작합니다. 정면·좌측면·뒷면·윗면·치수 기준·얼굴/원단/봉제선 상세를 확보하면, 제품 카드·사진 정합·3D 기준점·생산 사양 검수의 전 과정을 한 번에 검증할 수 있습니다. 이후 같은 흐름을 Tote Bag, Crossbody Bag, Regular T-shirt 순으로 확대합니다.
